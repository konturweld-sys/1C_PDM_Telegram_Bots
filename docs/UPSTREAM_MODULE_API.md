В исходных семи общих модулях обнаружено **74 экспортных процедур и функций**. Их сигнатуры необходимо сохранить либо заменить совместимым фасадом с тем же внешним контрактом. Особое внимание: токен бота должен перестать быть доступным клиентскому коду; методы консоли должны проходить отдельную серверную проверку прав.
